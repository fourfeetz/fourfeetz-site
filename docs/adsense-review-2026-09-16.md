# 애드센스 재신청 전 검수 — 2026-09-16

이전 거절 사유: 사용자가 전달한 **가치가 별로 없는 콘텐츠**.

운영 홈페이지와 저장소를 확인하고 로컬 프로덕션 빌드에 수정했다. 운영 배포, AdSense 계정 확인 및 재심사 제출은 수행하지 않았다. 아래 검증은 로컬 수정본에 대한 결과이며 승인 보장이 아니다.

## 콘텐츠 검토와 반영

Google은 독창적인 콘텐츠와 쉬운 탐색을 요구하며, 외부 자료나 영상에 자체적인 설명과 가치를 더할 것을 안내한다. 단순 글 수나 글자 수를 승인 기준으로 삼지 않았다.

- 한국어 홈페이지는 제작 서비스 안내가 중심이고, 상세 제작 기록은 상단 메뉴를 통해 찾아야 했다. 실제 프로젝트 기록 3편을 소개하는 본문 섹션과 전체 제작 기록·작업지 링크를 추가했다.
- 추천 글은 펫호텔 홍보영상 제작 경험, HARU/PORI 두 캐릭터 장면, 첫 이미지에서 완성 쇼츠까지다. 기존 본문의 프로젝트별 판단, 공개 프레임 및 완성 영상에 연결한다. 새로운 제작 경험이나 성과를 만들어 넣지 않았다.
- 기존 인사이트 목록은 이미 실제 제작 기록과 제작 가이드·도구 분석을 구분하고 있었다. 기존 Veo 3 아카이브의 검색 제외와 미번역 글의 영문 원문 연결 정책은 유지했다.
- 한국어 문의 페이지를 추가해 운영자, 이메일, 콘텐츠 정정, 작품 이용 및 개인정보 문의 방법을 공개했다. 영문 문의에도 오류 정정 안내를 추가했다.

## 최종 검증

- `npm run build`: 성공, TypeScript 검사 포함.
- `npm run lint`: 오류 0개. 변경하지 않은 추모영상 페이지와 PetMemorialMedia의 기존 img 경고 2개.
- `git diff --check`: 성공.
- 수정본을 `npm run start -- --port 3101`로 실행하여 HTTP 응답 검사.
- 사이트맵 215개 URL: 모두 HTTP 200, 자기 자신을 가리키는 canonical, H1 1개, AdSense 계정 메타 태그 확인. 중복 URL, 리디렉션 URL, noindex URL 없음.
- 해당 페이지들의 링크에서 추가로 발견한 내부 경로 62개: 최종 HTTP 오류 없음.
- 렌더링된 src/poster에서 추출한 고유 로컬 미디어 경로 172개: 누락 파일 없음. 미디어 전체 재생·외부 서비스 응답까지 검증한 것은 아님.
- 언어 전환, 정책 경로, 추모영상 서비스, 쿼리·앵커 및 대체 언어 메타데이터 관련 13개 단언 검사 통과.
- 모바일 폭의 실제 브라우저에서 홈페이지 제작 기록 카드와 문의 페이지의 표시, 줄바꿈 및 링크를 확인.

## 재신청 전에 남은 사항

1. 이 수정본을 운영 사이트에 배포하고 개인정보·문의 페이지, 제작 기록 링크, 계정 메타 태그가 공개 주소에서도 반영되는지 확인해야 한다.
2. AdSense 사이트 연결 상태 및 기존 ads.txt의 게시자 ID가 신청 계정과 일치하는지 계정에서 확인해야 한다.
3. 콘텐츠의 독창성·충분성은 Google의 재심사 판단 사항이다. 기술 검증만으로 거절 사유가 해소되었다고 단정할 수 없다. 도구 분석에 새로운 사실을 추가할 때는 직접 검증한 범위와 외부 출처를 구분하고, 실험 자료 없이 성과·횟수·경험을 보충하지 않는다.
4. 실제 광고를 활성화할 때 대상 지역에 필요한 Google 동의 관리 설정도 확인해야 한다. 이번 작업은 광고 쿠키 안내와 사이트 확인 메타 태그까지이며 CMP 도입은 포함하지 않는다.

## 첨부 글 분석 후 추가 반영

사용자가 첨부한 글은 [크몽: 구글 애드센스 승인 거절 사유 6가지와 해결 방법](https://kmong.com/article/3431)이다. 직접 경험과 판단을 보강하고, 접속 문제와 콘텐츠 문제를 구분하자는 방향을 참고했다. 글 수·글자 수·삭제할 글 개수에 관한 권장치는 Google의 공식 승인 조건이나 보장으로 취급하지 않았다. 사이트 연결에는 광고 스크립트 외에도 계정 메타 태그 등 공식 확인 방식이 있으므로 광고 스크립트를 무조건 추가하지 않았다.

이번 추가 작업은 일반적인 사용법만으로 끝나던 기존 리소스의 활용 가치를 높이는 데 집중했다.

| 리소스 | 새 작성 예시와 판단 기준 |
| --- | --- |
| 캐릭터 일관성 | HARU/PORI의 구별되는 외형·상대 크기·움직임 검토 지점 |
| 이미지 투 비디오 | 비 오는 창가 장면의 목적·한 가지 행동·환경 유지 조건 |
| 단편 제작 흐름 | 기준 이미지, 움직임, 편집, 마무리의 승인 단계와 되돌릴 단계 |
| 스토리보드 | 펫호텔 포트폴리오의 도착·돌봄·편안함·마무리 구성 |
| 제작 노트 | 확인 가능한 관찰, 검토 질문, 기록되지 않은 비용·실패의 구분 |

- 위 5개 리소스의 한국어·영어 10개 페이지에 각각 교육용 예시, 네 가지 작성 항목, 판단 설명, 근거 제작 기록 및 작성 가능한 작업지 링크를 추가했다.
- 예시는 공개된 기존 제작 기록에서 확인 가능한 내용에 근거한다. 원본 비공개 로그나 실제 사용 프롬프트처럼 제시하지 않았으며 확인되지 않은 비용·생성 횟수·실패 경험을 만들지 않았다.
- 한국어 리소스 8개의 영어 미리보기 문구 32개를 한국어로 바꾸었다.
- 한국어 인사이트의 추천 글이 영문 전용 글을 찾느라 표시되지 않던 오류를 수정했다. 한국어 제작 기록을 대체 추천하고 해당 글의 이미지·대체 텍스트를 사용한다.
- 인사이트에 실제 제작 기록, 교육용 작업지, 도구 분석을 구분하는 설명과 운영 주체·정정 요청 링크를 추가했다.
- 글을 일괄 삭제하거나 검색 제외로 승인 심사를 우회하지 않았다. 이전 수정 내용과 기존 공개 URL을 유지했다.

추가 검증: 최종 빌드 및 TypeScript 통과, 변경 파일 ESLint 오류·경고 없음. 예시 10개 페이지의 서버 렌더링과 네 개 작성 항목, 한국어·영어 인사이트 2개 페이지의 추천·정정 안내, 내부 링크 62개 응답을 검사했다. 마지막 번역 변경 후 8개 한국어 페이지의 32개 문구를 다시 확인했다. 실제 브라우저에서 스토리보드 예시의 데스크톱 표시도 검수했다. 운영 배포와 AdSense 재심사 제출은 여전히 미실행 상태다.
